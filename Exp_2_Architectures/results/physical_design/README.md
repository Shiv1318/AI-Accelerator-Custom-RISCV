# Physical design runs
OpenLane run reports, metrics and logs. Files larger than 5 MB (SPEF, DEF, SDF, gate-level netlist, GDS/MAG, full STA reports) are not included in this repository; they are kept in the lab archive.

## Which folder is which
- `soc_a2m0_d050/` - final accelerator SoC run RUN_2026.11.14_04.29.04 (ARCH 2, star, density 0.50): reports, metrics, LVS/DRC/antenna reports.
- `soc_a2m0/` - logs of the earlier OpenLane attempts (see report Table 4.1).
- `soc_base/` - baseline SoC (without accelerator) reports and metrics.
