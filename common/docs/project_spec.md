# Project Spec v0.1 (frozen, pending guide confirmation)

| Item | Value |
|---|---|
| CPU | PicoRV32, ENABLE_MUL=0, ENABLE_FAST_MUL=0 (CPU baseline = software shift-add) |
| Integration | AXI-Lite slave 3 @ 0x2000_0000 (ROM 0x0, SRAM 0x1_0000, UART 0x1000_0000) |
| Matrix | 2x2 (engines parameterized by N; wrapper/vectors 2x2 only) |
| Operands | 8-bit signed two's complement |
| Product / accumulator | 16-bit / 20-bit, wrap, no saturation |
| Clock | 20 ns = 50 MHz (matches top.sdc) |
| Reset | active-high async at SoC boundary; engines use active-low rst_n internally |
| Simulation | Verilator 5.052 (--binary --timing) |

## Register map (base 0x2000_0000)
| Offset | Reg | Access | Meaning |
|---|---|---|---|
| 0x00 | CTRL | W | bit0 START (ignored while busy) |
| 0x04 | STATUS | R | bit0 BUSY, bit1 DONE (cleared by START) |
| 0x08 | CYCLES | R | compute cycles of last operation |
| 0x10-0x1C | A[0..3] | W | int8, row-major |
| 0x20-0x2C | B[0..3] | W | int8, row-major |
| 0x30-0x3C | C[0..3] | R | 20-bit result, sign-extended to 32 |
| 0x40 | ID | R | {MULT [15:8], ARCH [7:0]} |

## Architectures (N=2)
| ARCH | Name | Latency |
|---|---|---|
| 0 | Iterative MAC (1 multiplier) | 8 cycles (N^3) |
| 1 | Parallel MAC (4 multipliers) | 2 cycles (N) |
| 2 | Systolic v2 (registered feed) | 5 cycles (3N-1) |

## Multipliers
MULT 0 = star (*), MULT 1 = radix-4 Booth. Also built and tested standalone: shift-add (8 cycles, sequential) and array (1 cycle, combinational).

## Status: FROZEN (14 Nov 2026)
Choices confirmed: 50 MHz, 8-bit signed, 2x2, PicoRV32. MATLAB not required (Python/NumPy is the reference).
Guide decisions: Wallace/Dadda and 4x4 only if easy; post-route accelerator-SoC result only if easy, otherwise the synthesis-only delta (+25%, ROM change noted) is reported.
